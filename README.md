# ڈیری مینجمنٹ (Dairy Management) 🥛
### موبائل ایپ برائے ٹیک اوے دودھ فراہمی و گاہک کھاتہ مینجمنٹ (Urdu Khata Management)

ایک مکمل، خوبصورت اور جدید موبائل ایپلیکیشن جو خاص طور پر ڈیری فارم کے ایڈمن کے لیے تیار کی گئی ہے تاکہ روزانہ کے ٹیک اوے (Self-Pickup) گاہکوں کا حساب کتاب، دودھ کا اسٹاک، نقد و ادھار (کھاتہ) اور ماہانہ واٹس ایپ بل باآسانی مینج کیا جا سکے۔

---

## 🌟 نمایاں خصوصیات (Core Features)

1. **مکمل اردو اور دائیں سے بائیں (RTL) انٹرفیس:**
   - خوبصورت اور واضح اردو خطاطی (`Noto Sans Arabic`)۔
   - تمام بٹن، کارڈز، ان پٹ فیلڈز اور انتباہات خالص اردو میں۔

2. **روزانہ کا ٹیک اوے ڈیش بورڈ (Daily Takeaway Dashboard):**
   - **ٹاپ اسٹیٹس بار:** کل دودھ گنجائش (مثلاً 65 لیٹر)، آج تقسیم شدہ دودھ اور فارم میں باقی اسٹاک۔
   - **انٹرایکٹو کاؤنٹر:** ہر گاہک کے لیے `[-] 2.0 L [+]` بٹن جس سے موقع پر دودھ کی مقدار تبدیل کی جا سکتی ہے۔
   - **قیمت کا فوری حساب:** دودھ کی مقدار بدلتے ہی فوراً کل رقم (روپے) اپ ڈیٹ ہوتی ہے۔
   - **ایک ٹیپ پر فراہمی تصدیق:** بٹن دباتے ہی کارڈ کا رنگ سبز ہو جاتا ہے اور ہیپٹک فیڈبیک وائبریشن ملتی ہے۔
   - **پل ٹو ریفریش:** اسکرین کو نیچے کھینچ کر تازہ ترین ڈیٹا لوڈ کریں۔

3. **ماہانہ بلنگ و کھاتہ (Monthly Khata & Ledger):**
   - ہر گاہک کا رواں ماہ کا کل دودھ (لیٹر)، کل بل، وصول شدہ رقم اور صاف واجب الادا (بقایا)۔
   - فلٹر ٹیبز: **تمام**، **کھاتہ دار (ادھار)**، اور **سپاٹ (نقد)**۔
   - **ادائیگی درج کریں ماڈل:** نقد، جاز کیش، ایزی پیسہ یا بینک کے ذریعے وصولی درج کریں۔
   - رقم درج ہوتے ہی کھاتہ فوراً ری کیلکولیٹ ہو کر بقایا کم ہو جاتا ہے۔

4. **تفصیلی واٹس ایپ انوائس جنریٹر (Automated WhatsApp Statement):**
   - ایک کلک پر گاہک کے واٹس ایپ پر تاریخ وار تفصیلی بل اردو فارمیٹ میں بھیجیں:
     ```text
     📋 *ماہانہ کھاتہ و بل تفصیل*
     👤 کسٹمر: چوہدری طارق گجر
     🗓️ مہینہ: ستمبر 2026
     --------------------------------
     🥛 *دودھ کی روزانہ تفصیل:*
     • 01/09: 2.0 لیٹر (480 روپے)
     • 02/09: 2.5 لیٹر (600 روپے)
     --------------------------------
     کل دودھ: 4.5 لیٹر
     دودھ کا بل: 1,080 روپے

     💰 *وصول شدہ ادائیگیاں:*
     • 10/09: 5,000 روپے (نقد)
     --------------------------------
     کل موصول شدہ: 5,000 روپے
     --------------------------------
     🔴 *صاف واجب الادا رقم: 9,400 روپے*

     شکریہ!
     *ڈیری مینجمنٹ*
     ```

5. **گاہک مینجمنٹ (Customer Directory):**
   - نیا گاہک شامل کریں / تبدیل کریں / حذف کریں۔
   - معمول کا کوٹہ (Default Liters)، ریٹ فی لیٹر، اور کسٹمر کی قسم (کھاتہ دار بمقابلہ نقد)۔
   - کسی بھی گاہک پر ٹیپ کر کے ان کا پچھلا تمام تاریخچہ اور ادائیگیاں دیکھیں۔

6. **دوہری سپورٹ (Supabase کلاؤڈ + آف لائن لوکل ڈیمو):**
   - اگر سپابیس انٹرنیٹ کنکشن یا کیز موجود نہ ہوں تو ایپ خودکار طور پر لوکل ڈیمو موڈ میں کام کرتی ہے جس میں حقیقت پسندانہ پاکستانی گاہک اور ماضی کا ڈیٹا پہلے سے موجود ہوتا ہے۔

## 🛠️ ٹیکنالوجی اسٹیک (Tech Stack)

- **فریم ورک:** React Native / Expo SDK 52 (TypeScript)
- **روٹنگ:** `expo-router` v4 (فائل بیسڈ روٹنگ)
- **اسٹیٹ مینجمنٹ:** Zustand v5
- **فونٹس:** `@expo-google-fonts/noto-sans-arabic`
- **فیڈبیک و اینیمیشن:** `expo-haptics`، `react-native-reanimated`
- **شیئرنگ و لنکنگ:** `expo-linking`، `expo-sharing`
- **ڈیٹا بیس / بیک اینڈ:** Supabase (PostgreSQL 15+, Row-Level Security, Views)

## 🚀 ایپ چلانے کا طریقہ (Getting Started)

### 1. انحصار انسٹال کریں:
```bash
npm install
```

### 2. ایکسپو ڈویلپمنٹ سرور چلائیں:
```bash
npx expo start
```

- **موبائل پر چلانے کے لیے:** اپنے اینڈرائیڈ یا آئی فون پر **Expo Go** ایپ کھولیں اور ٹرمینل میں موجود کیو آر کوڈ (QR Code) اسکین کریں۔
- **ویب پر چلانے کے لیے:** ٹرمینل میں `w` دبائیں۔

## 🗄️ سپابیس ڈیٹا بیس سیٹ اپ (Supabase Setup)

1. [Supabase.com](https://supabase.com) پر نیا پروجیکٹ بنائیں۔
2. بائیں جانب مینو سے **SQL Editor** کھولیں۔
3. پروجیکٹ کی فائل `supabase/migrations/20240926_init_dairy_schema.sql` کا تمام کوڈ کاپی کر کے SQL Editor میں پیسٹ کریں اور **Run** پر کلک کریں۔
4. سپابیس پروجیکٹ سیٹنگز سے اپنا **Project URL** اور **Anon Public Key** کاپی کریں۔
5. اپنی `.env` فائل میں درج کریں:
   ```env
   EXPO_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
   ```
6. ایپ دوبارہ شروع کریں۔ اب ایپ براہ راست آپ کے لائیو سپابیس ڈیٹا بیس سے خودکار ہم آہنگ ہوگی!
